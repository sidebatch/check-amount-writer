# 체크 금액 영문 변환기

수표(check)에 금액을 쓸 때, 숫자만 입력하면 영문 표기로 바로 변환해주는 웹 앱.

🔗 https://sidebatch.github.io/check-amount-writer/

## 기능

- 숫자 입력 → 영문 금액으로 실시간 변환 (예: `836.42` → "Eight hundred thirty-six 42/100")
- 실제 수표 폼 그대로의 미리보기: 날짜(DD MM YYYY, 오늘 날짜 자동 입력), 금액 박스($836.42), 영문 금액 라인
- 수표 권장 표기 준수: 복합 숫자에 하이픈 사용 (thirty-six), 센트는 `42/100` 분수 표기
- 영문 결과 문구를 탭하면 바로 복사
- UI 언어 전환: 우측 상단 EN / KR 버튼
- PWA 지원: 폰 홈 화면에 추가해 앱처럼 사용 가능, 오프라인 동작

## 폰에 설치하기

1. 폰 Chrome(또는 Safari)에서 위 링크 열기
2. ⋮ 메뉴(또는 공유 버튼) → **홈 화면에 추가**
3. 바탕화면 아이콘으로 바로 실행

## 개발

정적 단일 페이지(`index.html`) + 서비스 워커(`sw.js`) + 웹 매니페스트(`manifest.webmanifest`) 구성.
별도 빌드 과정 없이 `main` 브랜치에 푸시하면 GitHub Pages로 자동 배포됨.
